# Laporan Penyumpahan Wali / Pengampu dan Pencatatan Harta

**Judul**
- Perwalian: PELAKSANAAN SUMPAH TERHADAP WALI DAN PENCATATAN HARTA ANAK DI BAWAH PERWALIAN BERDASARKAN:
- Pengampuan: PELAKSANAAN SUMPAH TERHADAP PENGAMPU DAN PENCATATAN HARTA ORANG DI BAWAH PENGAMPUAN BERDASARKAN:
- Campuran: PELAKSANAAN SUMPAH TERHADAP WALI/PENGAMPU DAN PENCATATAN HARTA ANAK DI BAWAH PERWALIAN DAN ORANG DI BAWAH PENGAMPUAN BERDASARKAN:

**Baris penetapan**: Penetapan {pengadilan} Nomor: {nomor} tanggal {tanggal} perihal penetapan {Wali/Pengampu} An. {nama} atas diri {anak bernama/terampu} {nama}

## Kalimat hasil per penetapan

| Hasil | Kalimat |
|---|---|
| Berhasil, ada harta | Telah dilaksanakan pengambilan sumpah {Wali} an. {nama} dan ditandatanganinya Berita Acara Pengambilan Sumpah {Wali} Nomor: {nomor BA} tanggal {tanggal}, beserta pencatatan harta kekayaan {anak} berupa {uraian harta} dengan nilai {Rp}, sehingga dimintakan PNBP sebesar {Rp} |
| Berhasil, tidak ada harta | … serta Berita Acara Pencatatan Harta berstatus "Nihil" karena {anak} tidak memiliki harta kekayaan, sehingga PNBP tidak dapat dimintakan |
| Menolak disumpah | Pengambilan sumpah {Wali} an. {nama} berdasarkan {penetapan} tidak dapat dilaksanakan karena {Wali} menolak untuk diambil sumpahnya dengan alasan {alasan} |
| Tidak dapat ditemui | … tidak dapat dilaksanakan karena {Wali} tidak dapat ditemui di {alamat} ({alasan}) |
| Ditunda | … belum dapat dilaksanakan karena {alasan} dan akan dijadwalkan ulang |
| Dijadwalkan ulang virtual | … belum dapat dilaksanakan dan dijadwalkan ulang secara virtual melalui Zoom (Zoompah) |

## Butir kronologi baku
1. Tim mengawali pelaksanaan tugas pada hari {hari}, {tanggal}, dengan berkoordinasi terlebih dahulu di tingkat pemerintah desa/kelurahan.
2. Pada pukul {jam} WIB, Tim tiba di Kantor {Desa/Kelurahan} dan disambut baik oleh {nama dan jabatan}. Tim menjelaskan tupoksi BHP selaku {wali pengawas/pengampu pengawas} serta maksud kedatangan Tim.
3. Pada pukul {jam} WIB, Tim tiba di kediaman {Wali} an. {nama} dan menjelaskan hak, kewajiban, serta tanggung jawab {Wali} terhadap diri dan harta kekayaan {anak}.
4. Pada pukul {jam} hingga {jam} WIB, Tim melaksanakan pengambilan sumpah {Wali} an. {nama} dan penandatanganan Berita Acara. {Wali} disumpah sesuai agama yang dianutnya ({agama}), disaksikan oleh {saksi}.
5. Setelah seluruh kegiatan selesai dilaksanakan secara tertib, Tim kembali menuju Kantor Balai Harta Peninggalan Medan.
